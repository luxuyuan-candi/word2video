# Word2Video PC Web 应用页面功能设计

## 1. 文档目标

本文档用于定义 Word2Video PC Web 应用的首版页面功能设计，作为后续前端开发、接口联调、交互验收和任务拆分的基础。

当前产品重点不是直接生成最终视频文件，而是协助用户把文字剧本转化为可用于 AI 视频生产的结构化素材包，包括知识图谱、实体对象模型图、视频帧文字描述和帧级参考图片关联。

## 2. 产品定位

Word2Video 是一个面向 PC 用户的 AI 视频前期制作工具。用户输入文字剧本后，平台自动识别剧本内容，生成知识图谱，提取人物、物品、场景等实体对象，并引导用户为这些实体对象生成或上传参考图片。

最终，平台输出一份结构化创作资产：知识图谱、实体对象模型图片、视频分帧文字描述，以及每一帧关联的实体参考图。用户可以把这些内容带到其他 AI 图像或视频平台中继续生成画面和视频。

## 3. 目标用户

- AI 视频创作者：需要把剧本拆解成可执行的画面生成素材。
- 短片/故事创作者：希望保证人物、物品和场景在多帧画面中保持一致。
- 内容运营人员：需要批量把文案、广告脚本、口播脚本整理为视频生成提示词。
- 教育/培训内容生产者：需要把课程脚本拆分为清晰的画面描述。
- AI 工作流用户：熟悉 Midjourney、Stable Diffusion、Runway、可灵、即梦等外部生成工具，需要更稳定的前期素材管理。

## 4. 核心业务流程

```text
输入文字剧本
  ↓
平台解析剧本内容
  ↓
建立知识图谱并编织对象关系
  ↓
识别人、物、场景等实体对象
  ↓
引导用户为实体对象生成或上传参考图片
  ↓
沉淀知识图谱与实体对象模型图片
  ↓
根据剧本划分视频帧文字描述
  ↓
为每一帧关联相关实体参考图
  ↓
导出结构化素材包，供外部平台继续生成画面
```

## 5. 首版功能范围

### 5.1 包含功能

- 文字剧本输入与编辑。
- 剧本解析任务提交。
- 知识图谱生成与可视化展示。
- 实体对象识别，包含人物、物品、场景等类型。
- 实体对象详情查看与编辑。
- 引导用户为实体对象生成模型参考图片。
- 支持用户输入图片生成提示词。
- 支持用户上传自己的参考图片。
- 实体图片生成结果预览、选择和重新生成。
- 剧本分帧，生成每一帧的文字描述。
- 每一帧关联相关实体对象和实体参考图片。
- 导出最终素材包。
- 项目历史列表和项目详情恢复。

### 5.2 暂不包含功能

- 直接生成最终视频文件。
- 复杂时间线剪辑。
- 音频、配音和字幕合成。
- 多人协作。
- 商业化额度、支付和会员系统。
- 移动端专项适配。

## 7. 页面设计

### 7.1 项目工作台页

页面目标：让用户在一个页面内完成从剧本输入到素材包导出的核心流程。

建议路径：`/`

#### 页面布局

PC 端采用三栏工作台布局：

- 左侧：流程步骤导航和项目状态。
- 中间：当前步骤的主要编辑区。
- 右侧：上下文预览、详情面板和操作建议。

推荐布局：

- 左侧宽度：240px。
- 中间区域：自适应主工作区。
- 右侧宽度：360px 到 420px。
- 页面最小适配宽度：1366px。

#### 步骤导航

| 步骤 | 说明 |
| --- | --- |
| 1. 输入剧本 | 用户输入或粘贴完整文字剧本 |
| 2. 解析图谱 | 平台分析剧本并生成知识图谱 |
| 3. 确认实体 | 用户查看并修正人物、物品、场景等实体 |
| 4. 生成模型图 | 用户为实体对象生成或上传参考图片 |
| 5. 生成分帧 | 平台把剧本拆分为视频帧文字描述 |
| 6. 导出素材 | 导出知识图谱、实体图片和分帧描述 |

### 7.2 剧本输入页/步骤

页面目标：承载用户输入文字剧本，并启动剧本解析。

#### 核心模块

| 模块 | 功能说明 |
| --- | --- |
| 剧本编辑器 | 支持输入、粘贴、清空、字数统计 |
| 剧本标题 | 默认根据内容生成，可手动修改 |
| 内容类型 | 可选故事短片、广告脚本、教育讲解、产品介绍等 |
| 解析按钮 | 校验剧本后提交解析任务 |
| 示例入口 | 提供示例剧本，便于用户快速体验 |

#### 输入校验

| 字段 | 规则 |
| --- | --- |
| 剧本标题 | 可选，缺省时自动生成 |
| 剧本文字 | 必填，建议 100 到 10000 字 |
| 内容类型 | 可选，用于辅助解析 |

#### 页面状态

| 状态 | 页面表现 |
| --- | --- |
| 初始状态 | 展示剧本编辑器和示例入口 |
| 可解析状态 | 剧本达到最小字数后，解析按钮可点击 |
| 解析中 | 展示“分析剧本、抽取实体、建立关系”等阶段 |
| 解析失败 | 展示失败原因和重新解析按钮 |

### 7.3 知识图谱页/步骤

页面目标：把剧本中的对象、事件和关系可视化，帮助用户理解平台解析结果。

#### 核心模块

| 模块 | 功能说明 |
| --- | --- |
| 图谱画布 | 展示实体节点和关系连线 |
| 节点筛选 | 按人物、物品、场景、事件筛选 |
| 节点搜索 | 快速定位某个实体对象 |
| 图谱详情面板 | 点击节点后展示实体信息和相关关系 |
| 关系说明 | 展示对象之间的关系类型和来源文本 |

#### 图谱节点类型

| 类型 | 示例 |
| --- | --- |
| 人物 | 主角、配角、旁白角色 |
| 物品 | 道具、装备、产品、关键物件 |
| 场景 | 城市、房间、学校、办公室、自然环境 |
| 事件 | 相遇、冲突、转折、行动、结尾 |
| 概念 | 品牌、主题、情绪、风格关键词 |

#### 主要交互

1. 用户查看图谱整体结构。
2. 点击节点，右侧展示该对象的描述、关系和出现位置。
3. 用户可修改实体名称、类型、描述。
4. 用户可删除误识别实体，或手动新增实体。
5. 用户确认图谱后进入实体对象确认步骤。

### 7.4 实体对象确认页/步骤

页面目标：让用户确认剧本中需要保持视觉一致性的实体对象。

#### 核心模块

| 模块 | 功能说明 |
| --- | --- |
| 实体列表 | 按类型展示人物、物品、场景等对象 |
| 实体卡片 | 展示名称、类型、描述、出现次数、图片状态 |
| 实体编辑面板 | 修改实体名称、类型、外观描述、补充说明 |
| 批量操作 | 批量确认、批量忽略、按类型筛选 |

#### 实体卡片状态

| 状态 | 说明 |
| --- | --- |
| 待确认 | 平台识别到但用户未确认 |
| 已确认 | 用户确认该实体需要进入后续生成 |
| 已忽略 | 用户认为该实体不需要生成参考图 |
| 待生成图片 | 实体已确认但没有参考图片 |
| 已有图片 | 实体已绑定至少一张参考图片 |

### 7.5 实体参考图生成页/步骤

页面目标：引导用户为每个实体对象生成或上传模型参考图片。

#### 页面布局

- 左侧：实体对象列表和生成状态。
- 中间：当前实体的图片生成工作区。
- 右侧：实体描述、提示词、参考图片和生成历史。

#### 核心模块

| 模块 | 功能说明 |
| --- | --- |
| 当前实体信息 | 展示实体名称、类型、剧本描述和关系摘要 |
| 提示词编辑器 | 用户可输入或修改图片生成提示词 |
| 自动提示词建议 | 平台根据实体描述生成提示词草稿 |
| 参考图片上传 | 用户上传自己的图片作为参考 |
| 图片生成按钮 | 调用 AI 图片生成能力 |
| 生成结果画廊 | 展示多张候选图片 |
| 图片预览 | 放大查看图片细节 |
| 选为模型图 | 将某张图片设为该实体的主参考图 |
| 重新生成 | 基于当前提示词再次生成 |

#### 实体类型生成重点

| 实体类型 | 生成重点 |
| --- | --- |
| 人物 | 年龄、性别、服装、发型、表情、身份、风格一致性 |
| 物品 | 形状、材质、颜色、品牌感、使用场景 |
| 场景 | 空间结构、时间、光线、氛围、地点特征 |
| 概念 | 视觉符号、色彩、情绪和抽象表达 |

#### 主要交互

1. 用户选择一个待生成图片的实体。
2. 平台根据实体描述生成默认提示词。
3. 用户可以修改提示词。
4. 用户可以上传参考图片。
5. 用户点击生成图片。
6. 平台返回候选图片。
7. 用户预览候选图片，并选择一张作为实体模型图。
8. 用户可继续为下一个实体生成图片。

### 7.6 视频分帧页/步骤

页面目标：根据剧本生成视频帧文字描述，并为每一帧关联实体对象和参考图片。

#### 核心模块

| 模块 | 功能说明 |
| --- | --- |
| 分帧列表 | 按顺序展示每一帧 |
| 帧描述 | 展示该帧的画面文字描述 |
| 镜头信息 | 展示景别、镜头运动、视角、画面氛围等 |
| 关联实体 | 展示该帧涉及的人物、物品、场景 |
| 参考图片 | 展示关联实体的模型图片 |
| 提示词复制 | 一键复制该帧画面生成提示词 |
| 帧编辑 | 用户可修改帧描述和关联实体 |

#### 帧字段

| 字段 | 说明 |
| --- | --- |
| 帧序号 | 画面顺序编号 |
| 原文片段 | 该帧来源于剧本中的哪段文字 |
| 画面描述 | 可直接用于 AI 画面生成的文字描述 |
| 镜头语言 | 景别、角度、镜头运动 |
| 情绪氛围 | 紧张、温暖、孤独、明亮等 |
| 关联实体 | 该帧出现的人物、物品、场景 |
| 参考图片 | 关联实体的模型图 |

### 7.7 素材包导出页/步骤

页面目标：让用户检查并导出可在其他 AI 平台继续使用的结构化素材。

#### 导出内容

| 内容 | 格式建议 |
| --- | --- |
| 原始剧本 | `.txt` 或 `.md` |
| 知识图谱 | `.json` 和可视化截图 |
| 实体对象清单 | `.json` 或 `.csv` |
| 实体模型图片 | `.png` 或 `.jpg` |
| 分帧描述 | `.md`、`.json` 或 `.csv` |
| 帧与实体图片关联关系 | `.json` |

#### 导出选项

- 导出完整素材包。
- 仅导出实体模型图片。
- 仅导出分帧提示词。
- 复制指定帧提示词。
- 复制指定实体提示词。

### 7.8 项目历史页

页面目标：帮助用户查看和恢复过往项目。

建议路径：`/projects`

#### 列表字段

| 字段 | 说明 |
| --- | --- |
| 项目名称 | 默认取剧本标题，可重命名 |
| 内容类型 | 故事短片、广告脚本等 |
| 实体数量 | 已识别实体对象数量 |
| 已完成图片 | 已绑定参考图的实体数量 |
| 分帧数量 | 已生成的视频帧数量 |
| 状态 | 解析中、待确认实体、生成图片中、可导出、失败 |
| 更新时间 | 最近一次编辑时间 |
| 操作 | 打开、复制、导出、删除 |

## 9. 数据模型草案

```ts
  script: string;

  createdAt: string;
  updatedAt: string;

```

### 9.2 知识图谱

```ts
type GraphNodeType = 'character' | 'object' | 'scene' | 'event' | 'concept';

interface KnowledgeGraphNode {
  id: string;
  type: GraphNodeType;
  name: string;
  description: string;
  sourceText?: string;
  entityId?: string;
}

interface KnowledgeGraphEdge {
  id: string;
  sourceNodeId: string;
  targetNodeId: string;
  relation: string;
  description?: string;
  sourceText?: string;
}

interface KnowledgeGraph {
  nodes: KnowledgeGraphNode[];
  edges: KnowledgeGraphEdge[];
}
```

## 10. 接口预留

| 接口 | 方法 | 用途 |
| --- | --- | --- |
| `/api/projects` | `POST` | 创建项目并保存剧本 |

| `/api/projects/:projectId` | `GET` | 获取项目详情 |

## 12. 错误与异常处理

| 场景 | 处理方式 |
| --- | --- |
| 剧本为空 | 在输入区下方提示“请输入文字剧本” |
| 剧本过短 | 提示“建议至少输入 100 个字，以便识别完整关系” |
| 解析失败 | 展示失败原因，允许重新解析 |
| 图谱节点过多 | 默认折叠低优先级节点，并提供筛选 |
| 实体识别错误 | 允许用户编辑、忽略或新增实体 |
| 图片生成失败 | 展示失败原因，允许调整提示词后重试 |
| 参考图片上传失败 | 提示文件格式、大小或网络问题 |
| 分帧生成失败 | 允许重新生成，并保留已确认实体资产 |
| 导出失败 | 展示失败原因，允许重新导出 |

## 13. PC 端体验要求

- 工作台需要突出流程感，让用户清楚当前处于哪个步骤、下一步要做什么。
- 知识图谱画布需要支持缩放、拖拽、搜索和节点筛选。
- 实体对象列表需要适合批量处理，优先使用紧凑卡片或表格。
- 图片生成流程需要始终保留实体描述、提示词和参考图上下文。
- 分帧页面需要让用户快速复制单帧提示词，同时看到关联的实体模型图。
- 页面状态切换时需要保持主要工作区尺寸稳定，避免频繁跳动。
- 删除项目、删除实体图片等危险操作需要二次确认。

## 14. 首版开发优先级

### P0

- 项目工作台基础布局。
- 剧本输入与解析任务提交。
- 解析进度展示。
- 知识图谱展示。
- 实体对象列表与实体详情编辑。
- 实体图片生成流程。
- 视频分帧列表展示。

### P1

- 用户上传实体参考图片。
- 实体图片候选结果预览与主图选择。
- 帧描述编辑与实体关联调整。
- 素材包导出。
- 项目历史列表。

### P2

- 图谱节点高级筛选。
- 实体批量确认和批量忽略。
- 提示词模板。
- 多格式导出。
- 外部平台提示词格式适配。
